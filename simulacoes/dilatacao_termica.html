Ao receber energia, os átomos vibram com maior amplitude; devido à assimetria das interações entre eles, a distância média pode aumentar. As esferas e ligações são esquemáticas, não uma representação em escala.

Entenda os três tipos de dilatação

↔ Linear
ΔL = L₀αΔT

Considera a mudança no comprimento de uma barra. É apropriada quando a variação longitudinal é o foco.

▱ Superficial
ΔA = A₀βΔT

Considera a mudança de área de uma chapa. Para um sólido isotrópico, β ≈ 2α; o furo também se dilata.

⬡ Volumétrica
ΔV = V₀γΔT

Considera a mudança de volume de um corpo. Para um sólido isotrópico, γ ≈ 3α.

Modelo didático: os coeficientes são aproximações representativas e variam com a composição e a temperatura. A expansão visual é amplificada para facilitar a observação; os valores numéricos usam as fórmulas aproximadas de dilatação linear, superficial e volumétrica.
